# بوابة الرماد — سجل الحدود

**بوابة الرماد** لعبة محاكاة أصلية لتدقيق الوثائق واتخاذ القرارات والتحقيقات، باللغة العربية وفي عالم خيالي عام 1987. تعمل الواجهة على الهاتف، وتضم مشاهد Pixel Art مرسومة على Canvas، وثلاثة مستندات تفاعلية لكل مراجع، وتحقيقات تكشف أدلة مخفية، وراتبًا وغرامات وقرارات مالية للعائلة، ونهايات متفرعة.

## طريقة اللعب
1. اقرأ تعميم النوبة والتعليمات الرسمية.
2. افحص بطاقة الهوية، وتصريح العبور، وسجلّ الغرض.
3. قارن الاسم ورقم الملف والغرض والصلاحية والختم.
4. اختر السماح أو الرفض. عند وجود شك استخدم التحقيق الإضافي لكشف قرينة مخفية.
5. في نهاية النوبة راجع نتيجة عملك واختر نفقة البيت التي تستطيع دفعها.

## التقنية
ملف HTML مستقل مع CSS وJavaScript وCanvas؛ لا يحتاج إلى مكتبات تشغيل أو خطوط خارجية. تقدم اللاعب يُحفظ محليًا في المتصفح على الجهاز نفسه. هذه نسخة متصفح تجريبية، وليست بعدُ APK أو مشروع Godot.

## الأصالة
تستعير اللعبة فكرة تدقيق الوثائق واتخاذ القرارات من هذا النوع من الألعاب، لكن عالمها وشخصياتها وقصتها ونصوصها ورسوماتها أصلية.
