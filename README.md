# ميمي — حكاية صغيرة

لعبة رعاية وقصة تفاعلية ثنائية الأبعاد بأسلوب Pixel Art، تعمل مباشرة في المتصفح ومناسبة لشاشات الهواتف.

## المعاينة
بعد نجاح سير عمل GitHub Pages ستكون اللعبة متاحة على:
https://samalzubair.github.io/Mimi/

## طريقة اللعب
- افتح `index.html` في متصفح حديث أو استخدم رابط المعاينة بعد النشر.
- اختر **ابدأ الحكاية**، ثم اعتنِ بميمي من خلال الطعام واللعب والنظافة والحديث والقراءة والقيلولة والاستكشاف.
- لعبة ذاكرة مصغرة، أحداث قصة متفرعة، تزيين الغرفة ودفتر ذكريات.
- تقدم اللعبة يُحفظ محليًا في المتصفح على الجهاز نفسه.

## التقنية
نسخة تجريبية مستقلة HTML/CSS/JavaScript، بلا مكتبات تشغيل خارجية. رسم المشهد يتم على Canvas، وواجهة اللعبة تدعم RTL والعرض على الهاتف.
