# بوابة الرماد — سجل الحدود

محاكاة أصلية لتدقيق الوثائق واتخاذ القرارات في معبر حدودي خيالي. اللعبة باللغة العربية وتضم مشهد Pixel Art مرسومًا داخل Canvas، ومستندات تفاعلية، وتحقيقات، ورواتب وغرامات وقرارات للأسرة.

**معاينة الإصدار الحالي:**

## البحث التصميمي

راجع [DESIGN_RESEARCH.md](DESIGN_RESEARCH.md) لمعرفة مبادئ تصميم حلقة اللعب، الفن، الوثائق، الفحص، اقتصاد الأسرة، ومتطلبات النسخة التالية.

## طريقة اللعب الحالية
1. اقرأ تعميم النوبة والتعليمات.
2. افحص بطاقة الهوية وتصريح العبور وسجل المراجعة.
3. قارن الاسم ورقم الملف والغرض والصلاحية والختم.
4. اختر السماح أو الرفض، واستخدم التحقيق الإضافي عند الحاجة إلى دليل.
5. راجع الراتب والغرامات ثم اختر نفقة البيت.

## التقنية والحدود الحالية
- ملف HTML مستقل مع CSS وJavaScript وCanvas.
- لا يحتاج إلى مكتبات تشغيل خارجية أو خطوط خارجية.
- التقدم محفوظ محليًا في المتصفح على الجهاز نفسه.
- هذه نسخة متصفح تجريبية وليست APK أو مشروع Godot.
- الإصدار الحالي يحسّن رسم المشاهد، ولا يعني ذلك أن كل أنظمة اللعب النهائية قد اكتملت.

## الأصالة
تستخدم اللعبة مبادئ عامة من نوع محاكاة تدقيق الوثائق، لكن عالمها وشخصياتها وقصتها ورسوماتها ونصوصها أصلية. لا تتضمن أصولًا أو شعارات منسوخة من Papers, Please.
