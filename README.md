# بوابة الرماد — سجلّ الحدود

**بوابة الرماد** لعبة محاكاة وثائق وقرارات وتحقيقات أصلية باللغة العربية، تدور في جمهورية خيالية عام 1987. يعمل اللاعب موظفًا عند معبر حدودي؛ يفحص الهويات والتصاريح وسجلات الزيارة، ويختار السماح بالعبور أو الرفض أو فتح تحقيق إضافي.

## المعاينة
- رابط GitHub Pages بعد تفعيل النشر: https://samalzubair.github.io/Mimi/
- بديل مباشر للمعاينة: https://raw.githack.com/SamALZUBAIR/Mimi/main/index.html

إذا لم يعمل رابط Pages، افتح إعدادات المستودع: https://github.com/SamALZUBAIR/Mimi/settings/pages ثم اختر **GitHub Actions** في **Build and deployment**. يحتاج هذا التفعيل الأول إلى صلاحيات إعدادات المستودع.

## طريقة اللعب
1. اقرأ مذكرة النوبة والتعليمات الرسمية.
2. اضغط على بطاقة الهوية أو تصريح العبور أو سجل الغرض لقراءة بياناته.
3. قارن الاسم ورقم الملف والختم وتاريخ انتهاء التصريح بالتعليمات.
4. اختر السماح أو الرفض، أو استخدم التحقيق الإضافي لكشف معلومة مخفية عند وجود تناقض.
5. تابع أثر قراراتك على الراتب والغرامات والشك وخيوط القصة.

## التقنية
نسخة متصفح مستقلة بملف HTML واحد وCSS وJavaScript، مع واجهة RTL متجاوبة وحفظ محلي عبر المتصفح. لا تستخدم مكتبات تشغيل خارجية أو خطوطًا تتطلب اتصالًا. هذه نسخة لعب تجريبية للمتصفح وليست بعدُ إصدار Android/Godot.

## الأصالة
تستند إلى نوع ألعاب تدقيق الوثائق واتخاذ القرارات، لكن عالم اللعبة وشخصياتها ونصوصها ورسوماتها أصلية ولا تنسخ أصول لعبة أخرى.
